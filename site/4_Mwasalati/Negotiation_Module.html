تفاوض داخل نطاق، لا مزاد مفتوح. Negotiation inside a band — not an open auction.

inDriver-style counter-offers, bounded by the published route fare

آلية العرض المضاد تعطي الراكب صوتاً والسائق مرونة. لكن مواصلاتي قامت على مبدأ «الأجرة تُحدد بالخط لا بالزحام» — والمزاد المفتوح يكسر هذا المبدأ. الحل: الخط ينشر أرضية وسقفاً، والتفاوض كله يجري بينهما. السائق لا يستطيع أن يستغل مطراً، والراكب لا يستطيع أن يهبط بالأجرة تحت عتبة تشغيل المركبة. Counter-offers give the passenger a voice and the driver flexibility. But Mwasalati was built on "fares set per route, not per crowd" — and an open auction breaks that. The resolution: each line publishes a floor and a ceiling, and all negotiation happens between them. A driver cannot exploit rain; a passenger cannot bid below the vehicle's operating threshold.

التوتّر الذي يحلّه هذا التصميمThe conflict this design resolves

inDriver's mechanic vs. Mwasalati's published principle

آلية إنdrive قائمة على مزاد حر: الراكب يعرض، السائق يعرض مضاداً، بلا سقف ولا أرضية. لكن مادة مواصلاتي المنشورة تقول نصّاً: «الأجرة تُحدد بالخط لا بالزحام». المزاد الحر هو تسعير بالزحام تحديداً — في المطر يرتفع، وفي الركود ينهار تحت تكلفة الوقود. الاثنان لا يجتمعان بلا وسيط. inDriver's mechanic is a free auction: passenger bids, driver counters, no floor and no ceiling. But Mwasalati's published material says plainly that fares are set per route, not per crowd. A free auction is crowd pricing — it spikes in rain and collapses below fuel cost in a lull. The two cannot coexist unmediated.

01
الخط ينشر نطاقاً لا رقماً

كل خط له floor وceiling. الأرضية تُشتق من تكلفة تشغيل المركبة، والسقف من قرار الخط. التفاوض حرّ بينهما ومستحيل خارجهما.

02
التفاوض على المقعد لا على المركبة

إن‑درايفر يساوم على السيارة كاملة. هنا الوحدة مقعد — فالسائق قد يقبل ثلاثة عروض بأسعار مختلفة في نفس الرحلة، وكلها داخل النطاق.

03
العرض له عمر

٤٥ ثانية ثم يسقط. السائق يتحرك على الخط، فعرضٌ قديم يعني موقعاً كاذباً. العدّاد خطّي لأنه ساعة لا زخرفة.

04
السقف يبقى ١٤ مقعداً مهما بلغ الطلب

لا يوجد مسار يبيع المقعد الخامس عشر. النطاق يضبط السعر، والسعة تضبط الحمولة — لا يتنازل أحدهما للآخر.

05
القبول ضغطة مستمرة

نفس إيماءة تسليم سودا إكسبرس. القبول التزام مالي على شاشة تُلمس في زحام — الضغطة الواحدة تُخطئ.

تعارض الأجرة — ما يزال مفتوحاً

ملفاتك تحمل رقمين متناقضين لنفس الخط. هذا الملف لا يحسم أيّهما صحيح، لكنه يُظهر شيئاً مفيداً: لو كان نطاق خطة مواصلاتي صحيحاً، فرقم الإنفوجرافيك يقع تحت الأرضية — أي أنه ليس نقطة داخل النطاق، بل رقم من نظام تسعير آخر تماماً.

آلة الحالةNegotiation state machine

Every transition is bounded — no state can leave the band
// A seat request moves through exactly these states.

  composed  — passenger sets fare + seats. Clamped to [floor, ceiling].
      │
      ▼
  broadcast — visible to drivers assigned to this line only.
      │            Not to "nearby drivers" — line assignment is the filter.
      ▼
  countered — 0..n driver counters. Each also clamped to the band.
      │            Each carries expires_at = now + 45s.
      ├──────────────► expired   (driver moved; offer is stale)
      ├──────────────► withdrawn (passenger raised their own offer)
      ▼
  accepted  — requires held_ms ≥ 1200. Seat is decremented atomically.
      │            Rejected if it would breach the 14-seat cap.
      ▼
  ticketed  — QR minted, binding passenger + seat + boarding point.
      │
      ▼
  completed ──► settled  ← the ONLY green state in this module

واجهة الحزمةSDK surface

Line-scoped, band-enforced server-side
import { Mwasalati } from '@hawil/mwasalati-sdk'

const mws = Mwasalati.init({ locale: 'ar', dir: 'rtl', currency: 'SDG' })

/* ── Lines · public read ─────────────────────────────── */
mws.lines.list()          // → 5 lines, each with band + boarding points
mws.lines.band(line_id)  // → { floor, ceiling, published_at }
mws.lines.points(line_id) // approved boarding points — no open-street pickup

/* ── Passenger ───────────────────────────────────────── */
mws.requests.compose({ line_id, point_id, seats, fare_per_seat })
  // throws FARE_OUT_OF_BAND — clamping is server-side too
mws.requests.broadcast(request_id)
mws.requests.counters(request_id)      // live stream, 45s TTL each
mws.requests.accept(counter_id, { held_ms })
  // throws SEAT_CAP_REACHED · OFFER_EXPIRED · INTENT_TOO_SHORT

/* ── Driver ──────────────────────────────────────────── */
mws.driver.inbox(line_id)              // only their assigned line
mws.driver.counter(request_id, fare)  // also band-clamped
mws.driver.seatsRemaining(trip_id)    // hard ceiling 14

/* ── Ticket ──────────────────────────────────────────── */
mws.tickets.get(ticket_id)   // QR binds passenger + seat + point
mws.tickets.verify(qr)      // driver-side scan at boarding
