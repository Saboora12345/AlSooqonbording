المبادئ الحاكمةGoverning principles

Five rules the logistics layer enforces structurally
01
البوليصة تُولد من طلب، لا من فراغ

create() ترفض أي استدعاء بلا order_token صالح. لا يوجد مسار لإنشاء شحنة يتيمة — وبذلك يستحيل أن يوجد طرد بلا طلب يقابله.

02
السعر على الحجم لا الوزن

التسعير يأخذ الأكبر بين الوزن الفعلي والحجمي المشتق من رمز التغليف. التاجر يختار رمزاً من سلّم مغلق، فلا يقدّر الأبعاد بنفسه ولا يخطئ في الفرز.

03
الحبل لا ينفكّ

كل حدث تتبّع يحمل رقم البوليصة ورمز الطلب معاً. الشاشة تعرضهما مقترنين دائماً — لا يوجد عرض يُظهر أحدهما وحده.

04
الأحداث التي لا رجعة فيها تُقاوم اللمسة الواحدة

التسليم للمندوب يتطلب ضغطاً مستمراً ١٫٢ ثانية. الإفلات يلغي في ٢٠٠ مللي. هذا ليس زخرفة — هو حاجز نية على شاشة تُلمس بيد مشغولة.

05
الحركة عقد مكتوب لا ذوق شخصي

المنحنيات والمُدد مثبّتة كرموز أدناه. أي مكوّن جديد يستدعي من الجدول — لا يخترع قيمة.

عقد الحركةMotion contract

Every curve chosen, every duration justified by frequency

المنحنيات المدمجة في المتصفح ضعيفة ولا تعطي إحساس القصد. كل قيمة هنا مأخوذة عن قرار، وكل مدة مربوطة بعدد مرات رؤية المستخدم للحركة.Built-in browser easings are too weak to read as intentional. Every value below is a decision, and every duration is tied to how often the user sees it.

واجهة الحزمةSDK surface

Merchant-scoped writes, public reads on tracking only
import { Sudaexpress } from '@hawil/sudaexpress-sdk'

const sdx = Sudaexpress.init({ locale: 'ar', dir: 'rtl', currency: 'SDG' })

/* ── Quoting ─────────────────────────────────────────── */
sdx.rates.quote({ order_token, to, pack_code, actual_kg, pieces })
  // → [{ service, price, eta_days, coverage }]  · sorted by price
sdx.coverage.check(state, area)   // → { served, sector, cutoff }

/* ── Waybill ─────────────────────────────────────────── */
sdx.shipments.create({ order_token, service, parcel })
  // throws ORDER_TOKEN_REQUIRED — there is no orphan path
sdx.shipments.label(waybill, { format: 'a6' | 'thermal80' })
sdx.shipments.cancel(waybill)      // only while status = draft|ready

/* ── Pickup ──────────────────────────────────────────── */
sdx.pickup.windows(sector, date)   // → live capacity per slot
sdx.pickup.book(waybill, window_id)
sdx.shipments.handover(waybill, { courier_id, held_ms })
  // held_ms < 1200 is rejected — deliberate-intent gate

/* ── Tracking · public, no auth ──────────────────────── */
sdx.track.get(waybill || order_token)   // either key resolves
sdx.track.subscribe(waybill, cb)

/* ── UI kit ──────────────────────────────────────────── */
import { QuoteList, WaybillCard, PickupSheet,
         TetherTimeline, HoldToHandover, PackPicker,
         CoverageBadge, StatusPill } from '@hawil/sudaexpress-ui'
