كتالوج واحد. واجهتان. One catalog. Two surfaces.

The product layer shared by the merchant workspace and the public storefront

حزمة تطوير الكتالوج هي الطبقة التي يكتب فيها التاجر المنتج مرة واحدة، فيظهر للزبون فوراً بنفس البنية والرموز والحالات. الواجهتان تقرآن من نفس المخطط — لا نسخ، لا ازدواج، لا انحراف. The Catalog SDK is the layer where a merchant writes a product once and the customer sees it immediately — same schema, same tokens, same states. Both surfaces read one contract. No copies, no drift.

المبادئ الحاكمةGoverning principles

Five rules the SDK enforces at the schema level, not by convention
01
الكتالوج عام، غرفة العمل خاصة

واجهة الزبون تقرأ بدون حساب. واجهة التاجر تتطلب مصادقة. نفس البيانات، صلاحيتان — يُفرض عند نقطة النهاية لا في الواجهة.

02
ثنائية اللغة في المخطط لا في الترجمة

كل حقل نصي هو كائن {ar, en}. المنتج بلا اسم إنجليزي لا يُنشر. لا اعتماد على ترجمة وقت العرض.

03
المتغير هو وحدة المخزون

الرصيد يُمسك على مستوى المتغير لا المنتج. نفاد مقاس لا يُسقط المنتج من العرض، ويظهر مشطوباً في محدد المقاس.

04
الحالة سلّم طيني لا إشارة مرور

مسودة ← مراجعة ← منشور تُقرأ بتدرجات لون واحد. الأخضر محجوز للتسوية المالية فقط، والأحمر لا يُستخدم كحالة كتالوج.

05
النشر مشروط لا اختياري

publish() ترجع قائمة موانع. زر النشر يُعطَّل حتى تُستوفى — الجودة تُفرض قبل الظهور لا بعد الشكوى.

واجهة الحزمةSDK surface

Public reads need no auth. Writes are merchant-scoped.
import { AlSooqCatalog } from '@alsooq/catalog-sdk'

const sooq = AlSooqCatalog.init({
  locale: 'ar', dir: 'rtl', currency: 'SDG', theme: 'canon'
})

/* ── Customer surface · public, no account ──────────── */
sooq.categories.list()
sooq.products.list({ category, cursor, limit: 24 })
sooq.products.get(id)
sooq.products.search(q, { category, inStock: true })
sooq.cart.add(sku, qty)        // SKU, never product id
sooq.cart.lines()

/* ── Merchant surface · auth required ───────────────── */
sooq.merchant.drafts.create(payload)
sooq.merchant.drafts.update(id, patch)
sooq.merchant.media.upload(file, { role: 'scale' })
sooq.merchant.variants.set(id, matrix)
sooq.merchant.inventory.adjust(sku, delta, { reason })
sooq.merchant.publish(id)
  // → { ok: false, blockers: ['media.scale', 'title.en'] }

/* ── UI kit · both surfaces, same tokens ────────────── */
import { ProductCard, PriceBlock, VariantAxis,
         StatusPill, MediaSlots, PublishGate } from '@alsooq/catalog-ui'
